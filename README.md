# ClearPoint Website

ClearPoint is a fictional AI-empowered Agile consulting company created as a portfolio project.

The site was designed to show how a small consulting business could use a clear, approachable digital presence to explain services, guide prospective clients, and support consultation requests.

## Live Site

https://clearpoint-website.netlify.app/

## Project Goal

The goal of this project was to create a responsive multi-page website for a small business using a simple, beginner-friendly development stack.

The project focused on:

- Clear information architecture
- Warm, approachable branding
- Agile and AI-focused service messaging
- Responsive design
- Simple user interactions
- Consultation request workflow
- Accessibility-minded structure

## Pages Included

- Home
- About
- Services
- Case Studies
- FAQ
- Contact
- Privacy Policy
- Terms & Conditions
- 404 Page

## Key Features

- Responsive desktop and mobile layouts
- Sticky frosted navigation

- FAQ accordion

- Date selection
- Morning / Afternoon / Evening preference
